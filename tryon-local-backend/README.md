# TRY ON 本地 8GB 显卡后端

该后端在 Windows NVIDIA 显卡上运行 CatVTON，并自动读取实际独立显存，提供：

- YOLO 人体关键点识别；
- 单人、头脚完整和包袋遮挡检查；
- 4GB / 6GB / 8GB 自动分辨率档位，8GB 默认 768×1024 FP16 真实试穿；
- 内搭与外套按顺序串行生成；
- 所有照片只在自己的电脑和手机之间传输。

## 安装

1. 安装 **Python 3.10 64位**、**Git for Windows** 和最新版 NVIDIA 驱动。
2. 双击 `install_windows.bat`，首次安装和下载模型可能需要较长时间。
3. 双击 `start_windows.bat`。浏览器访问 `http://127.0.0.1:7865/health`，看到 `"ready":true` 即启动成功。返回值中的 `vram_gb` 是程序实际检测到的独立显存，不取 Windows 总共享显存。

## 让 iPhone 安全访问

1. 电脑和 iPhone 安装 Tailscale，并登录同一免费账号。
2. 后端保持运行，在电脑终端执行：

   ```powershell
   tailscale serve 7865
   ```

3. 复制命令显示的 `https://设备名.网络名.ts.net` 地址。
4. 在 TRY ON 的“设置 → 本地AI后端”中粘贴该地址并测试连接。

Tailscale Serve 只允许同一账号下的设备访问，不会把个人照片公开到互联网。

## 8GB 显存建议

- 关闭游戏、剪辑软件和其他占用显存的程序；
- 首次运行会下载数GB模型；
- 单件衣服生成一次，内搭＋外套会连续生成两次；
- 如果仍显存不足，把 `start_windows.bat` 中分辨率改为 `640 × 896`。

## 当前边界

遮挡检查会阻止包袋、雨伞等覆盖身体的照片进入试穿。被完全遮住的真实身体无法从单张照片准确恢复，因此不会伪造所谓“精确补全”。真实可旋转3D网格需要更高显存的独立重建模型，不在该8GB后端中冒充实现。
